# 🛍️ 好友集市（Buddy Shop）

朋友 / 对象之间的小小购物集市。你们可以在上面「上架」东西，再用
**积分、真钱、或自定义奖励**（抱抱 / 亲亲 / 做饭 / 洗衣服……）来交换。

## ✨ 功能

- **上架东西**：标题、描述，三种结算方式任选
  - 🪙 **积分**：买家扣积分、卖家得积分
  - 💴 **真钱**：只记账，实际转账线下完成（买家点「我已转账」→ 卖家点「确认完成」）
  - 🎁 **自定义奖励**：比如「一个抱抱」「洗一次衣服」，确认完成即可
- **积分系统**：注册送 50 积分，可以转赠给 TA，买卖自动结算
- **订单管理**：我买到的 / 我卖出的，待处理、已付款、已完成、已取消
- **中英双语**：右上角一键切换 中文 / English

## 🚀 本地运行

需要 Node.js（本环境已装好 v24）。不需要安装任何第三方依赖。

```bash
cd friend-shop
node server.js
```

然后手机浏览器打开：**http://127.0.0.1:3000**

> 停止：按 `Ctrl + C`。数据保存在 `data/shop.db`，删掉该文件即清空所有数据。

## 👥 怎么两个人一起用（不在一块也能用）

软件本身已经是「联网版」，两个账号共用同一份数据。现在只监听本机
`127.0.0.1`，所以目前只有这台手机自己能访问。要让对方也能访问，有几种方式：

### 方式一：内网穿透（最快，零成本，临时用）
在你的电脑/服务器上把本机 3000 端口暴露到公网，生成一个公网链接发给 TA。

```bash
# 用 cloudflared（Cloudflare 免费隧道）
cloudflared tunnel --url http://127.0.0.1:3000
# 会返回一个 https://xxx.trycloudflare.com 链接，发给对方即可
```

### 方式二：部署到免费云平台（长期稳定，推荐）
把整个 `friend-shop` 文件夹上传到 Render / Railway / Fly.io 等免费平台，
启动命令填 `node server.js`，并把环境变量 `HOST` 设为 `0.0.0.0`。
平台会给你一个公网地址，两人都能访问。

> 注意：免费平台的「睡眠」机制可能让数据偶尔延迟，但功能都正常。

### 方式三：自己的服务器 / 家用电脑
在服务器上跑 `node server.js`，用 `HOST=0.0.0.0` 让它监听所有网卡，
再配好防火墙/安全组开放 3000 端口，用服务器 IP 访问。

```bash
HOST=0.0.0.0 node server.js
```

## 🔐 说明

- 密码用 scrypt 加密存储，不存明文。
- 真钱订单只是「记账」，请线下自行转账，软件不涉及真实支付。
- 首次注册赠送 **50 积分**，改 `server.js` 顶部的 `START_POINTS` 即可调整。
